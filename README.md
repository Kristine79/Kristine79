## 🔎 SEOFlow AI — AI SEO Directory Campaign Platform

🌐 **[Live Demo](https://seoflowai.vercel.app/)** · **[GitHub](https://github.com/Kristine79/seoflowai)**

AI-assisted platform for managing SEO directory campaigns from research to verified results.

SEOFlow AI was created from a real client task: processing a large campaign across SEO and business directories. Instead of repeating the same work manually, I turned the workflow into a reusable product combining AI-assisted research, automation, human-in-the-loop actions, verification and reporting.

### Real-world validation

The product was tested on a real campaign covering **77 platforms**:

- 5 placed
- 7 submissions sent
- 23 requiring human action
- 14 unavailable / externally blocked
- 28 not suitable

The important part is not the number itself, but the workflow: real registrations, moderation, external restrictions, manual actions and evidence-based status tracking.

### Core workflow

```text
DISCOVER → AUDIT → SELECT → PREPARE → SUBMIT → VERIFY → MONITOR → REPORT
Key engineering ideas
AI-assisted directory research and SEO analysis
platform prioritization
AI-generated platform-specific content
browser automation with Playwright
human-in-the-loop execution
evidence-first verification
campaign status history
post-submission monitoring
client reporting

Principle: automate repetitive work, stop when a human is required, and never claim success without evidence.
